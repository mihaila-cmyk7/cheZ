# Шахматы на троих — Telegram Mini App

Онлайн-игра для троих. Сервер на Node.js (WebSocket-комнаты), клиент — одна HTML-страница, бот открывает её как Mini App.

## Правила
- Доска из 96 клеток: три сектора по 8 вертикалей × 4 горизонтали, по одному у каждого игрока (по 16 фигур). В игре ваш сектор всегда внизу.
- **Горизонтали** — кольца из 24 клеток вокруг центра: правый край сектора продолжается левым краем соседа.
- **Вертикали** проходят через центр: правая половина (e–h) уходит в сектор справа, левая (a–d) — в сектор слева, зеркально (h→a, g→b, f→c, e→d). **Диагонали** тоже огибают центр; в центре сходятся 6 клеток.
- Все фигуры ходят как в обычных шахматах, но по этим линиям, то есть и через центр, и по кольцу. Пешка идёт к центру, переходит в соседний сектор и превращается на его первой линии. Подробные схемы ходов каждой фигуры — в окне «Правила» в игре.
- Ходят по часовой стрелке: белые → чёрные → красные.
- Шаха и мата нет: партия идёт до **взятия короля**. Потерявший короля выбывает, его фигуры остаются серыми «камнями» (их можно брать). Побеждает последний оставшийся. Предупреждение «Королю угрожают!» показывается.
- Рокировки и взятия на проходе нет. Двойной ход пешки с первой линии есть.
- Можно сдаться; после партии — «Играть ещё».

## Устройство
- `game.js` — правила и геометрия доски (общий файл для сервера и клиента). Доска задана склейкой сторон клеток; все лучи ладьи и слона, ходы коня, короля и пешки считаются из неё.
- `layout.js` — раскладка клеток на плоскости для отрисовки (общая для клиента и тестов).
- `bot.js` — боты, `server.js` — комнаты, WebSocket и Telegram-бот, `index.html` — клиент.

## Две доски
На старте выбирается доска: **«На троих»** (3 сектора с кольцами, `game.js` + `layout.js`) или **«Т»** 14×11 с квадратными клетками и обычными ходами (`tgame.js`). Выбор хранится в комнате, друзья по ссылке играют на той же доске; правила в окне «Правила» подстраиваются под доску.

## Вид 3D, цвета, чат
- Кнопка **3D/2D** вверху: доска наклоняется, фигуры стоят; тяните доску пальцем, чтобы повернуть и наклонить («Сбросить вид» возвращает).
- **🎨 Цвета**: каждый игрок выбирает цвет своих фигур и своего поля (в лобби и в игре), остальные это видят.
- **💬 Чат** комнаты (последние 60 сообщений, не чаще раза в 0,7 с).

## Что есть в интерфейсе
- **Стартовое меню:** «Играть с ботами», «Создать игру с друзьями» или «Войти» по ссылке-приглашению либо коду комнаты (если открыть игру по ссылке, меню пропускается).
- **Боты** (`bot.js`): простой жадный ИИ — берут незащищённые фигуры, не подставляются, тянутся к королям соперников. В лобби с друзьями кнопка «Добавить ботов» занимает свободные места.
- **Правила:** кнопка «Правила» вверху открывает плашку с правилами.
- **Фон:** кнопка «Фон» — 8 готовых вариантов (включая «Как в Telegram») и выбор своего цвета; выбор запоминается на устройстве.

## Быстрый тест без Telegram
```bash
npm install
npm test          # тесты правил
npm start         # http://localhost:3000
```
Откройте `http://localhost:3000/?name=Аня`, нажмите «Создать игру с друзьями» — появится код комнаты. Двум другим вкладкам: `http://localhost:3000/?room=КОД&name=Боря` и `...&name=Вика` (или вставьте код в поле «Войти»). Когда зайдут трое, игра начнётся. Для игры с ботами достаточно одной вкладки.

## Запуск в Telegram
1. В **@BotFather**: `/newbot` → получите токен.
2. Разместите сервер где-нибудь с HTTPS (Render, Railway, Fly.io или VPS с Caddy/nginx). Переменные окружения:
   - `BOT_TOKEN` — токен бота (включает проверку подлинности игроков и бота на `/start`)
   - `WEBAPP_URL` — публичный адрес сервера, например `https://chess3.example.com`
   - `PORT` — порт (если хост не задаёт сам)
3. В **@BotFather**: `/newapp` → выберите бота, укажите `WEBAPP_URL`, задайте короткое имя (например `chess`).
4. Задайте `MINIAPP_LINK=https://t.me/<имя_бота>/chess` — тогда кнопка «Пригласить друзей» отправляет прямую ссылку `?startapp=КОД`, и друзья попадают сразу в вашу комнату.
5. Напишите боту `/start` → «Играть».

## Ограничения
- Комнаты хранятся в памяти: при перезапуске сервера партии теряются.
- Один экземпляр сервера (без масштабирования на несколько процессов).
